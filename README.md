## Introduction

This repository contains practical examples of CSS inheritance and SCSS features, based on educational materials from Harvard University. It demonstrates how to create reusable styles and apply consistent formatting to different HTML elements using CSS and SCSS.

## Topics Covered

- CSS inheritance fundamentals
- Styling multiple elements with shared CSS rules
- CSS class selectors
- SCSS placeholder selectors using `%`
- Reusing styles with the `@extend` directive
- Creating reusable message styles
- Customizing success, warning, and error messages
- Compiling SCSS into CSS

## Practical Example

The repository demonstrates three types of message components:

- **Success Message** — Green background
- **Warning Message** — Orange background
- **Error Message** — Red background

SCSS uses a shared `%message` placeholder and `@extend` to reuse common styling across these components.

## Learning Approach

The examples demonstrate how CSS and SCSS can reduce repetitive styling, organize stylesheets, and maintain consistent designs across multiple HTML elements.
